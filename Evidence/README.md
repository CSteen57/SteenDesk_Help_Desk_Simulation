# Evidence

This directory contains the screenshots and supporting scripts referenced by the SteenDesk ticket documentation.

## Organization

Evidence is grouped by ticket under [`Helpdesk_Tickets`](./Helpdesk_Tickets/). Each ticket folder uses numbered filenames so the screenshots follow the same order as the troubleshooting and validation steps in the corresponding ticket.

Ticket #007 also includes the PowerShell scripts used for its workstation replacement and file recovery tasks.

## Reviewing the Evidence

Start with the [ticket index](../Helpdesk_Tickets/README.md), open a ticket, and follow its embedded screenshots in sequence. The Markdown ticket should be treated as the primary record; this directory stores the supporting files.
